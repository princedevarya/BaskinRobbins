# Baskin Robbins By Shanzzy Franchise

A website project for Baskin Robbins By Shanzzy Franchise, built to showcase the store, present its menu, and provide visitors with an engaging online experience.

## Overview

The project focuses on creating a visually appealing and user-friendly website that reflects the brand's identity. It features menu sections, store photography, and interactive visual elements to help visitors explore the franchise online.

## Features

- **Menu Showcase:** Displays available ice cream offerings.
- **Photo Gallery:** Presents store and product photographs directly on the website.
- **Interactive Animations:** Adds subtle visual effects to enhance the browsing experience.
- **Responsive Layout:** Designed to work across different screen sizes.
- **Franchise Information:** Provides a dedicated online presence for the store.
